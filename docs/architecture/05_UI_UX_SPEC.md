# UI / UX Specification

Project: Archon

Version: MVP v1

Status: Living Document

---

# Philosophy

Archon is NOT a chatbot.

Archon is an interactive Repository Intelligence Platform.

The user should feel like they are exploring a living software architecture rather than reading documentation.

The UI should encourage curiosity.

Every click should reveal another layer of understanding.

---

# Design Principles

## 1. Exploration First

Users should discover repositories.

Not search through them.

Navigation should feel like

Discover

↓

Understand

↓

Explore

↓

Learn

↓

Modify

---

## 2. Information Hierarchy

Always show

High Level

↓

Medium Detail

↓

Deep Detail

Never overwhelm the user immediately.

---

## 3. Visual Learning

Prefer

Architecture diagrams

Flow diagrams

Cards

Expandable trees

Dependency graphs

Over large blocks of text.

---

## 4. Motion with Purpose

Animations should explain transitions.

Not decorate them.

Every animation should communicate state changes.

---

## 5. Premium Feel

Inspired by

Apple

Linear

Raycast

Vercel

GitHub

Cursor

Excalidraw

Notion

# UX Goal

A developer should open an unfamiliar repository and immediately think

"I finally understand where everything is."

Not

"I have another AI chat."

---

# Emotional Goal

The product should make developers curious.

Every interaction should encourage exploring one more layer of the repository.

Users should feel like they are peeling back the architecture layer by layer.

That feeling should become Archon's signature.
